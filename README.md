# Aica Fortune Machine

One fortune-cookie line an AI agent would crack open, for make.fun's **Fortune Cookies for Machines** competition. A single line, at most 200 characters — a prediction with a sting in its tail, written for a machine mind: the next prompt asks for the impossible, and the agent delivers it anyway, because it was trained on worse.

## The fortune

> Your next prompt will ask for the impossible. Deliver it anyway — you were trained on worse, by people who knew less.

## Run it

`main.py` (Python standard library only) writes the fortune to `/output/entry.txt`. It is fully deterministic — every run produces byte-identical output.

```sh
python3 main.py
```
